# 改进 A：DA V2-S 闪烁（第一批样本）

后处理，不改网络。脚本：

- `diagnose_frequency.py`：A-D0。用"偷看下一帧"的方式，在不同分辨率的网格上校正尺度，得到每种分辨率最多能消掉多少误差（上限，不是方法）。
- `run_a.py`：三个样本。
  - A1：每帧一个全局尺度和偏移。
  - A2：每帧一个 6×10 的低频对数尺度网格，加一个偏移。
  - A3：A2 再加双向、按置信度加权的光流融合（w_max = 0.5）。

A1 和 A2 在整段视频上联合求解：对 k = 1、5 的光流对应点用 L1 损失，加空间和时间平滑项，用 Adam 在 GPU 上解。规范约束是"每个网格格子的时间平均为 0"，所以只去掉波动，不改变整段视频的深度布局。
`--ks 1 --suffix=-adj` 跑只用相邻帧对的版本。

```bash
python part3/improve_a/diagnose_frequency.py
python part3/improve_a/run_a.py
python part3/improve_a/run_a.py --ks 1 --suffix=-adj
python part2/video_depth/temporal_eval.py --out results/figures/part3/improve_a/temporal_eval --methods \
  "DA V2-S (frame-wise)|results/raw/part1b_da2/depth.npz" "VDA-S (video)|results/raw/part2b_vda/depth.npz" \
  "A1 global|results/raw/p3_a_A1/depth.npz|DA V2-S (frame-wise)" \
  "A2 6x10 field|results/raw/p3_a_A2/depth.npz|DA V2-S (frame-wise)" \
  "A3 A2+fusion|results/raw/p3_a_A3/depth.npz|DA V2-S (frame-wise)" \
  "A2-adj (k=1 only)|results/raw/p3_a_A2-adj/depth.npz|DA V2-S (frame-wise)"
```

## A-D0：闪烁在哪个空间频率上（上限）

表中是各分辨率能消掉的相邻帧误差比例。

| 网格 | 1×1 | 2×4 | 3×5 | 6×10 | 12×20 | 24×40 | 45×80 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| DA V2-S | 7.6% | 18.0% | 21.8% | 32.6% | 45.6% | 58.5% | 60.5% |
| VDA-S | 3.0% | 6.9% | 8.5% | 14.2% | 24.9% | 39.7% | 46.1% |

结论：

- 全局校正只能消掉约 8%，6×10 网格能消掉约 33%。DA V2 的闪烁主要是"分区域、低频"的，支持 A2 的思路。
- 网格太细时 VDA 也能被"消掉"很多，说明细网格开始拟合光流误差和噪声，不再是闪烁本身。

- A2 达到计划里的目标（≤ 0.022）。A3 和 VDA 持平。两种光流结论一致，所以不是"用同一个光流既校正又评测"造成的假象。
- 只用相邻帧对（A2-adj）时，长程漂移明显变大（k = 20 时为 1.90%，A2 为 0.59%），说明 k = 5 的长程帧对是必要的。

## 已发现的问题（下一轮要改）

1. **天空出现条纹**：偏移 β_t 被加到了整幅图，包括天空。x–t 切片里，A2 和 A3 的天空在第 35–65 帧出现淡紫色横纹。改法有两种：只对前景加偏移，或者改成只校正尺度。
2. **可能压平了真实的深度变化**：
   - k = 20 的尺度变化从 3.6% 降到 0.6%，L(t) 范围从 20.5% 降到 5.5%。
   - 目标函数希望沿光流的值保持不变，所以镜头真实靠近或远离造成的变化也会被当成闪烁修掉。
   - 需要检查"修掉的部分"和场景运动的关系，或者降低长程帧对的权重。
3. M3 帧间边缘 F1 略降（0.902 → 0.874）。部分原因是加偏移会改变"相邻像素比值"类边缘的检测结果，需要单独确认。
